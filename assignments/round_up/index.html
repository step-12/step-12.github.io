    Round up#

    Write a program to round a number up to the nearest 10.

    Here are some examples

    NumberRounded
    00
    110
    210
    2330
    2930
    105110

    Start your program as follows:

    1  | 3 13 0 1
5  | 4 0  0 0
9  | 0 0  0 0
13 |

    Expect the number to be input in cell 5. The answer is expected in cell 6.

    Try not to divide.
