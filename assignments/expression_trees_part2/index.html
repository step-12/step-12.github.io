    Expression Trees: Part 2#

    Instructions#

    For each expression or statement:

    • Draw the expression tree.
    • Perform name lookups using the current values.
    • Evaluate the expression step by step.
    • Show the final result.

    For function based expressions, clearly show:

    • Lookup → Argument Evaluation → Function Call → Assignment → Updated Table

    1. The Lookup Table#

    Initial Values#

    NameValue
    a12
    b5
    c3
    d2

    Evaluate the following expressions:

    • a + b * c - d
    • (a + b * c) > (d ^ 2 + 5)
    • a * (b - c) >= (a - d) * 2
    • (a + b) == (c * d + 11)
    • ((a - b) * c) + d < a + (b ^ 2)
    • (a + b > c * d) && (a - c < b + d)
    • (a * c >= b ^ d) || ((a - b) == c + d)
    • ((a + b) > (c * d)) && ((a - d) != (b + c))

    2. Names Meet Numbers#

    Values#

    x = 15, y = 4, z = 3, p = 2

    Create the lookup table and evaluate:

    1. x + y * z
    2. (x - y) * (z + p)
    3. x * (y + z) - p
    4. (x + y) / (z + p)
    5. x % (y + z) + p
    6. x ^ p - y * z
    7. x + 5 > y * z
    8. (x - y) == z + p

    3. A Table That Keeps Moving#

    Initial Values#

    score = 20, bonus = 5, level = 2, lives = 3

    Create the lookup table and execute the following in order:

    1. score = score + bonus * level
    2. bonus = score % 7 + lives
    3. score = (score + bonus) * level
    4. level = bonus - lives + 1
    5. score = score / level + bonus
    6. lives = score % level
    7. score > 20
    8. bonus == lives

    Maintain the table after every statement and show the final table.

    4. Follow the Values#

    Initial Values#

    a = 8, b = 3, c = 4, d = 2

    Create the lookup table and execute:

    1. a = a + b * c
    2. b = a % (c + d)
    3. c = (a - b) * d
    4. d = a + b - c
    5. a = (a + c) / d
    6. b = a * d + c
    7. a > b
    8. c == d
    9. a + b > c * d

    Maintain the table after every statement and show the final table.

    5. Boolean Values Keep Changing#

    Initial Values#

    age = 18, score = 60, attempts = 3, passed = false

    Create the lookup table and execute:

    1. passed = score >= 50
    2. score = score + 10
    3. passed = score >= 50 && attempts < 3
    4. attempts = attempts - 1
    5. passed = score >= 50 && attempts < 3
    6. score = score + attempts * 5
    7. passed = (score >= 70) || (attempts == 0)
    8. age = age + 1
    9. age >= 18 && passed == true

    Maintain the table after every statement and show the final table.

    6. Functions with Boolean Arguments#

    Assume:

    isGreater(x, y) → x > y
isEqual(x, y)   → x == y
both(x, y)      → x && y
either(x, y)    → x || y

    Values#

    a = 8, b = 5, c = 3, d = 10

    Create the lookup table and evaluate:

    1. isGreater(a, b)
    2. isEqual(b + c, a)
    3. isGreater(a + b, c * d)
    4. isEqual(a - b, c)
    5. both(a > b, c < d)
    6. either(a < b, c == 3)
    7. both(a + b > d, c * 2 == a - 2)
    8. either(a * c > d, b + c == a)

    7. Nested Functions and Expressions#

    Assume:

    add(x, y)       → x + y
subtract(x, y)  → x - y
multiply(x, y)  → x * y

    Values#

    a = 10, b = 5, c = 3, d = 2

    Create the lookup table and evaluate:

    1. add(a, multiply(b, c))
    2. multiply(add(a, b), c)
    3. subtract(a, multiply(b, c + d))
    4. add(multiply(a, b - c), d)
    5. multiply(add(a + 2, b), subtract(c + 5, d))
    6. add(multiply(a, b), multiply(c + d, a - 2))
    7. subtract(multiply(a + b, c), add(d, b - c))
    8. multiply(add(a, b * c), subtract(a + d, c))

    For nested calls, show the evaluation order of the inner and outer function calls.

    8. The Table and the Functions#

    Assume:

    add(x, y)       → x + y
multiply(x, y)  → x * y
subtract(x, y)  → x - y

    Initial Values#

    a = 6, b = 4, c = 2, result = 0

    Create the lookup table and execute in order:

    1. result = add(a + 2, b)
    2. a = result - c
    3. result = multiply(a, b + c)
    4. b = result % 7
    5. result = add(a + b, c * 2)
    6. c = result - a * b
    7. result = multiply(add(a, b), c)
    8. a = result / (b + c)
    9. result = add(a * 2, multiply(b + 1, c))

    Maintain the table after every statement and show the final table.

    9. Follow Everything#

    Assume:

    add(x, y)       → x + y
subtract(x, y)  → x - y
multiply(x, y)  → x * y
isGreater(x, y) → x > y

    Initial Values#

    a = 7, b = 4, c = 3, d = 2, result = 0, valid = false

    Create the lookup table and execute the following in order:

    1. result = add(a + b, c * d)
    2. a = multiply(result - b, c)
    3. valid = isGreater(a, result)
    4. result = add(a, multiply(b + c, d))
    5. b = subtract(result, a * d)
    6. c = add(a % b, d ^ 2)
    7. valid = isGreater(c + b, a - d)
    8. result = multiply(add(a, b * c), subtract(c, d))
    9. d = subtract(result, multiply(a, b))
    10. result = add(multiply(a + d, b), c)
    11. valid = isGreater(result, a + b)
    12. a = subtract(result, add(b, c * d))
    13. result = multiply(add(a, b), subtract(c, d))
    14. valid = isGreater(result, a * b)

    Maintain the lookup table after every statement.
