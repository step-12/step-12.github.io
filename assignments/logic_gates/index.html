    Logic Gates#

    English statements#

    Analyze the given scenarios, identify the corresponding truth tables, and represent them using Boolean expressions and logic gates.

    1. Security System#

    The alarm should activate when the system is armed and either the front door or the back door is open.

    2. Payment System#

    A transaction should be approved when the card is valid and the account has sufficient funds, provided that the card has not been blocked.

    3. Automatic Door#

    The automatic door should open when a person is detected and the system is enabled, unless the door is in maintenance mode.

    4. Motor#

    The motor runs when the start button is pressed, the power is available, and the emergency stop is not pressed.

    5. Heater#

    The heater turns on when the temperature is low and either the automatic mode or manual mode is enabled.

    Build AND, OR, and NOT Without Using the Corresponding Gate#

    Build the basic gates without directly using the gate you are trying to construct.

    Tasks#

    1. Build an AND gate using other available gates.
    2. Build an OR gate using other available gates.
    3. Build a NOT gate using other available gates.

    De Morgan’s Laws#

    Understand and implement De Morgan’s Laws using Boolean expressions, truth tables, and logic gates.

    The goal is to understand the concept thoroughly, rather than simply memorizing the two laws. Verify each law using truth tables and demonstrate the equivalent logic using gates.

    Tasks#

    1. Implement and verify De Morgan’s First Law: ¬(A · B) = ¬A + ¬B

    2. Implement and verify De Morgan’s Second Law: ¬(A + B) = ¬A · ¬B

    3. Construct the truth table for each law and verify that both sides produce the same output for every input combination.

    4. Build the corresponding logic-gate circuits for both sides of each law and verify that they are equivalent.

    5. For the following expressions, apply De Morgan’s Law and draw the equivalent logic circuit:

      • ¬(A · B · C)
      • ¬(A + B + C)

    Comparator#

    Implement three separate comparison operations for two 1-bit binary inputs:

    A
B

    The three operations are:

    • A > B
    • A < B
    • A = B

    For each comparison operation, provide its own:

    • Truth table
    • Boolean expression
    • Logic-gate implementation

    Example Scenario#

    For the input:

    A = 1
B = 0

    The expected outputs are:

    A > B → 1
A < B → 0
A = B → 0
