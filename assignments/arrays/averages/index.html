      Averages#

      In this assignment, you will draw a bar chart representing an array of numbers. You will also draw a horizontal line representing the average of those numbers.

      Requirements#

      • The screen width and height must be configurable.
      • The width of each bar must be configurable. It must not be less than 1.
      • The gap between consecutive bars must be configurable.
      • The horizontal and vertical scales must be determined by the data.
      • The largest value in the array must correspond to 90% of the screen height. Use the same vertical scale for every value.
      • If the bars extend beyond the screen width, the excess data may be truncated.
      • Draw the bars in r.DARKBLUE.
      • Draw the average as a horizontal line in r.RED.
      • Use r.SKYWHITE for the background.

      Getting Started#

      Start with the following array of 10 numbers:

      const data = [12, 45, 78, 23, 91, 56, 34, 67, 89, 40];

      Before writing any code, write down a checklist of the tasks you need to complete. Break the problem down and think about what you need to figure out before you begin implementing it.

      Once your program works with the initial data, test it with other arrays. Try different lengths and values, including randomly generated data.

      Scaling#

      The chart must adapt to the data and the dimensions of the screen. You cannot assume that one unit of data corresponds to one pixel.

      Vertical scale#

      Suppose your screen is 400 pixels tall and the largest number in your array is 100. The tallest bar should be 360 pixels tall (90% of the screen height).

      If another number in the array is 50, its bar should be 180 pixels tall. A number of 25 should produce a bar 90 pixels tall.

      Notice that all bars use the same scale. You must not scale each bar independently to fill the screen. The relative heights of the bars must accurately represent the relative sizes of the numbers.

      The average line must use this same scale. Its position should correspond to the average value, just as each bar’s height corresponds to its data value.

      If you change the data and the largest number becomes 200, the tallest bar should still occupy 90% of the screen height. The other bars and the average line must adjust accordingly.

      Horizontal scale#

      The horizontal scale determines where each bar is drawn along the screen’s width.

      The bar width and the gap between consecutive bars are configurable. For example, if each bar is 4 pixels wide and the gap is 2 pixels, each bar begins 6 pixels after the previous bar begins.

      If there is not enough room to draw all the bars, the bars that extend beyond the screen width may be truncated. You do not need to squeeze all the data into the available width.
