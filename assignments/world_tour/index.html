      A World Tour#

      You’ve learned how to use loops. Now we’re going to use them to recreate a series of images with Raylib.

      For each exercise, you will be given an image. Recreate the image using a loop.

      The dimensions and number of strips in your program should be configurable.

      1. Spain#

      Recreate the image using Raylib.

      • The reference image is 440 × 440 pixels.
      • The dimensions of your drawing should be configurable.
      • The number of strips should be configurable.
      • The strips should have equal width.
      • Use r.RED and r.GOLD.
      • Repeat the pattern shown in the image.

      Prime numbers#

      A prime number is a whole number greater than 1 that has exactly two factors: 1 and itself.

      For example:

      2, 3, 5, 7, 11, 13, 17, 19

      are prime numbers.

      0 and 1 are not prime numbers.

      FizzBuzz#

      FizzBuzz is a classic programming exercise.

      Start with the number 0 and consider each number in order.

      For each number, apply these rules:

      • If the number is divisible by both 3 and 5, it is FizzBuzz.
      • If the number is divisible by 3, it is Fizz.
      • If the number is divisible by 5, it is Buzz.
      • Otherwise, it is simply the number itself.

      For example:

      Notice that 15 is FizzBuzz, because it is divisible by both 3 and 5.

      In this exercise, use the FizzBuzz result to determine how each strip should be drawn.

      • Ordinary numbers should be r.WHITE.
      • Fizz strips should be r.GREEN.
      • Buzz strips should be r.RED.
      • FizzBuzz strips should be drawn as a gradient.
      • The gaps should be r.BLACK.

      Recreate the gradient shown in the reference image.

      The first six exercises used vertical strips. The next exercises use a grid of cells.

      Your program should determine the position and appearance of each cell using its row and column.
