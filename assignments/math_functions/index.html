    Shun the funcs#

    A small collection of exercises for getting comfortable with functions, composition, multiple arguments, domains, and the occasional mathematical ambush.

    1. A Simple Sum#

    Evaluate:

    f(x) = x + 2
g(x) = 3x

f(2) + g(3)

    2. In n Out#

    Evaluate:

    f(x) = 3x
g(x) = x - 2

f(g(2))

    3. Karthik Calling Karthik#

    Evaluate:

    f(x) = square(x)
g(x) = f(2x) + x

g(2)

    4. Karthik calling Karthik calling…Karthik?#

    Evaluate:

    f(x) = square(x)
g(x) = f(f(x)) + f(2x)

g(5)

    5. More Than One Thing at a Time#

    Evaluate:

    f(x) = 2x
g(x,y) = f(x) * f(y)

g(2,3)

    6. The Eagle’s nest#

    Evaluate:

    f(x) = 2x
g(x,y) = f(f(x)) + f(f(y))
h(x) = g(x,x) + g(x+1,x+1)

h(10)

    7. Pappu passes#

    Evaluate:

    f(x) = x + 2
g(x) = 2x
h(x,y) = x + y(x)

k(x) = h(x,f) + h(x,g)

k(5)

    Pay particular attention to what it means for a function itself to be passed as an argument.

    8. If tables could talk#

    Write a function corresponding to the following table:

    xyzr
    0102020
    01511
    1102010
    115115

    Assume x will always be either 0 or 1.

    Try to express the function using mathematical operations rather than program-style cases.

    9. Dis order#

    Give an example of two functions f and g such that:

    f(g(x)) = g(f(x))

    for all values of x for which both sides are defined.

    There are many possible answers. Find one.

    10. Same as similar#

    Consider:

    f(x) = x/x
g(x) = 1

    Are f and g the same function?

    Think carefully about the domain of each function before answering.

    11. Lunatic calendar#

    Write a function that calculates the number of days in a month, given the number of the month from 0 to 11.

    Use only mathematical functions. No program-style if conditions are allowed.

    MonthDays
    031
    128
    231
    330
    431
    530
    631
    731
    830
    931
    1030
    1131

    The challenge is not simply to reproduce the table. Find a compact mathematical expression that produces the correct answer for every month.

    12. The Plot Thickens#

    Consider:

    f(x) = x + 1

g(x) = f

h(x) = g(5)

    What is:

    h(5)

    Pay attention to the difference between a function and the result of calling a function.
