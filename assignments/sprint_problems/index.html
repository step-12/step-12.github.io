    Sprint Assignments#

    1. Are Two Numbers Equal?#

    Write a program that checks whether two given numbers are equal.

    Input: Two numbers a and b.

    Output: 1 if the numbers are equal, otherwise 0.

    Examples:

    • Input: 5, 5 → Output: 1
    • Input: 5, 3 → Output: 0

    2. Sum of All Numbers from M to N#

    Write a program that calculates the sum of all integers from m to n, including both endpoints.

    Input: Two numbers m and n.

    Output: The sum of all numbers from m through n.

    Examples:

    • Input: 3, 7 → Output: 25
    • Input: 1, 5 → Output: 15

    3. Sum of the First N Even Terms#

    Write a program that calculates the sum of the first n positive even numbers.

    Input: A number n.

    Output: The sum of the first n even numbers.

    Examples:

    • Input: 3 → Output: 12
    • Input: 5 → Output: 30

    4. Sum of Even Numbers from M to N#

    Write a program that calculates the sum of all even numbers between m and n, including both endpoints.

    Input: Two numbers m and n.

    Output: The sum of all even numbers from m to n.

    Examples:

    • Input: 3, 10 → Output: 28
    • Input: 1, 6 → Output: 12

    5. Second Greatest of Three Numbers#

    Write a program that finds the second greatest number among three given numbers.

    Input: Three numbers a, b, and c.

    Output: The second greatest number.

    Examples:

    • Input: 10, 5, 8 → Output: 8
    • Input: 3, 9, 7 → Output: 7
    • Input: 5, 5, 2 → Output: 5

    6. Ceiling of Quotient#

    Write a program that calculates the ceiling of the quotient of two positive integers. The ceiling is the smallest integer greater than or equal to the quotient.

    Input: Two positive integers a and b.

    Output: ceil(a / b).

    Examples:

    • Input: 10, 3 → Output: 4
    • Input: 12, 3 → Output: 4
    • Input: 7, 2 → Output: 4

    7. Modulo#

    Write a program that finds the remainder when one number is divided by another.

    Input: Two positive integers a and b.

    Output: The remainder of a divided by b.

    Examples:

    • Input: 17, 5 → Output: 2
    • Input: 20, 4 → Output: 0
    • Input: 7, 3 → Output: 1

    8. Subtraction#

    Write a program that subtracts one number from another.

    Input: Two numbers a and b.

    Output: The value of a - b.

    Examples:

    • Input: 10, 3 → Output: 7
    • Input: 3, 10 → Output: -7
    • Input: 8, 8 → Output: 0

    9. 2^x#

    Write a program that calculates 2 raised to the power x.

    Input: A non-negative integer x.

    Output: The value of 2^x.

    Examples:

    • Input: 0 → Output: 1
    • Input: 3 → Output: 8
    • Input: 5 → Output: 32

    10. Absolute Value of X#

    Write a program that calculates the absolute value of a given number x.

    Input: A number x.

    Output: The absolute value of x.

    Examples:

    • Input: 7 → Output: 7
    • Input: -7 → Output: 7
    • Input: 0 → Output: 0

    11. Even or Odd#

    Write a program that determines whether a given number is even or odd.

    Input: An integer n.

    Output: 1 if the number is even, otherwise 0.

    Examples:

    • Input: 8 → Output: 1
    • Input: 13 → Output: 0
    • Input: 0 → Output: 1

    12. Nth Fibonacci Term#

    Write a program that finds the nth Fibonacci number. The Fibonacci sequence starts with 0, 1, and each subsequent number is the sum of the previous two numbers.

    Input: A non-negative integer n.

    Output: The nth Fibonacci number.

    Examples:

    • Input: 0 → Output: 0
    • Input: 1 → Output: 1
    • Input: 6 → Output: 8
    • Input: 10 → Output: 55

    13. Factorial#

    Write a program that calculates the factorial of a non-negative integer n.

    Input: A non-negative integer n.

    Output: The value of n!.

    Examples:

    • Input: 0 → Output: 1
    • Input: 4 → Output: 24
    • Input: 5 → Output: 120

    14. a^x#

    Write a program that calculates a raised to the power x.

    Input: Two numbers a and x, where x is a non-negative integer.

    Output: The value of a^x.

    Examples:

    • Input: 2, 5 → Output: 32
    • Input: 3, 4 → Output: 81
    • Input: 10, 0 → Output: 1
