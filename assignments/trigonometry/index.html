      Trigonometry Challenges#

      You have spent some time with our trigonometry primer .

      The primer was not meant to be a list of formulas for you to memorize. It was meant to give you a way of thinking about angles, circles, coordinates, sine, cosine, radians and polar coordinates.

      Now we are going to use those ideas.

      For each of the following challenges, write a small Raylib program. Each challenge is independent. You should be able to run each program by itself.

      There is one important rule:

      The trigonometry should be the interesting part of the problem.

      Do not introduce keyboard input, mouse input, animation, physics, projectiles, or other machinery that is unrelated to the problem. Use the Raylib drawing functions you already know.

      If you get stuck, go back to the primer. Find the picture that looks like the thing you are trying to construct. Then ask yourself what information that picture gives you.

      1. Points Around a Circle#

      Create a program called circle_points.js.

      Your program should create a window of:

      • width: 400
      • height: 400

      Draw a circle with:

      • center: (200, 200)
      • radius: 150

      Now place 12 points evenly around the circumference of the circle.

      The points should correspond to the 12 equally spaced positions around one complete revolution.

      For example, one point should be at the top of the circle, one at the right, one at the bottom, and one at the left.

      Draw each point as a small circle.

      Requirements#

      • Store the number of points in a constant.
      • Calculate the position of every point.
      • Do not hard-code the coordinates of the 12 points.
      • Do not write 12 separate drawing statements.
      • Use a loop.
      • Every point should lie on the circumference.
      • The angular spacing between consecutive points should be equal.

      Think carefully about the following:

      • What is one complete revolution in radians?
      • If there are 12 points, how much should the angle change from one point to the next?
      • Once you know an angle and a radius, how do you find the point on the circle?

      If your points are not evenly spaced, do not try to fix the coordinates individually. Something is wrong with your understanding of the angle.

      2. Draw a Regular Polygon#

      Create a program called polygon.js.

      Draw a regular polygon with:

      • center: (200, 200)
      • radius: 150
      • number of sides: 7

      In other words, draw a regular heptagon.

      The polygon should be drawn by calculating the positions of its vertices and then drawing lines between consecutive vertices.

      Requirements#

      • Store the number of sides in a constant.
      • Store the center and radius in constants.
      • Calculate all seven vertices.
      • Do not hard-code any vertex coordinates.
      • Use a loop.
      • Every vertex must lie on the same circle.
      • The vertices must be equally spaced around the circle.
      • Connect the last vertex back to the first vertex.

      You are not being asked to use a polygon-drawing function.

      Instead, think back to the previous challenge.

      You already know how to find points at equally spaced angles around a circle.

      What changes when there are seven points instead of twelve?

      One detail#

      The polygon does not have to have one particular orientation. It is perfectly fine if one vertex is at the top, or if one of the edges is horizontal.

      What matters is that it is actually a regular polygon.

      3. Draw a Sine Wave and a Cosine Wave#

      Create a program called waves.js.

      Draw a graph showing one complete cycle of both the sine and cosine functions.

      Use a window of:

      • width: 600
      • height: 400

      Put the origin of your graph at approximately:

      (50, 200)

      Use the horizontal direction for the angle and the vertical direction for the function value.

      Your graph should show:

      • the sine curve
      • the cosine curve
      • the horizontal axis
      • the vertical axis

      You should draw the curves yourself by calculating a sequence of points.

      Requirements#

      For each curve:

      1. Start at an angle of 0.
      2. Increase the angle in small steps.
      3. Calculate the function value at each angle.
      4. Convert that value into a screen coordinate.
      5. Connect consecutive points with lines.

      Draw enough points that the curves appear smooth.

      You should show exactly one complete revolution along the horizontal axis.

      Scale the vertical values so that:

      • 1 is visibly above the horizontal axis.
      • -1 is visibly below the horizontal axis.
      • 0 lies on the horizontal axis.

      Mark these points#

      Somewhere on the graph, clearly mark the important values:

      • where the sine curve is 0
      • where the sine curve reaches 1
      • where the sine curve reaches -1
      • where the cosine curve reaches 1
      • where the cosine curve reaches -1

      You do not need to make a sophisticated graphing system. The goal is to make the relationship visible.

      Think about the primer#

      You have already seen a point moving around a circle and its vertical projection creating a wave.

      This is that idea again.

      Ask yourself:

      Why does a point moving at a constant angular speed produce a wave when we look at one of its coordinates?

      And:

      Why are the sine and cosine curves the same shape, but shifted relative to one another?

      4. Draw an Ellipse Without Using an Ellipse Function#

      Create a program called ellipse.js.

      Draw an ellipse centered at:

      (300, 200)

      with:

      • horizontal radius: 200
      • vertical radius: 100

      You may draw the axes or a surrounding rectangle if they help you see what is happening.

      You may not use Raylib’s ellipse-drawing function.

      Instead, calculate points around the ellipse and connect them with lines.

      Requirements#

      • Start with an angle of 0.
      • Move around one complete revolution.
      • Calculate a point for each angle.
      • Connect consecutive points.
      • Make the curve smooth.
      • Close the curve at the end.
      • Do not hard-code points.
      • Do not use an ellipse primitive.

      You already know how to calculate a point on a circle.

      The question is:

      What happens if the horizontal coordinate is scaled differently from the vertical coordinate?

      Start with the circle.

      Then think about what would happen if you stretched every point horizontally by one amount and vertically by another amount.

      That is the entire idea behind this challenge.

      Check your result#

      Your ellipse should pass through approximately these four points:

      (500, 200)
(300, 300)
(100, 200)
(300, 100)

      If it does not, check your coordinate calculation rather than adjusting individual points.

      5. What Angle Is That?#

      Create a program called angle.js.

      We will give you two fixed points:

      A = (100, 300)
B = (350, 150)

      Draw:

      • point A
      • point B
      • a line from A to B

      Now determine the angle that the line from A to B makes with the horizontal axis.

      Display that angle on the screen in degrees.

      Also draw the components#

      To make the geometry visible, draw a right triangle using the two points.

      Starting at A:

      • draw horizontally until you are directly below or above B
      • then draw vertically until you reach B

      You should therefore be able to see:

      • the horizontal distance between the points
      • the vertical distance between the points
      • the original line from A to B

      You should not calculate the angle by measuring it yourself or by entering the answer as a constant.

      Calculate it from the coordinates.

      Requirements#

      • The two points must remain constants.
      • Calculate the horizontal difference.
      • Calculate the vertical difference.
      • Calculate the angle using JavaScript’s Math functions.
      • Convert the result to degrees for display.
      • Do not hard-code the final angle.

      There is an important detail here.

      The angle returned by JavaScript’s inverse trigonometric functions is in radians.

      The number you display should be in degrees.

      Think back to the primer:

      Why does the computer give you radians?

      And:

      How do you convert an angle from radians to degrees?

      Extension#

      Change the coordinates of B.

      Try points in different directions from A.

      For example, try a point:

      • to the right
      • to the left
      • above
      • below
      • diagonally in each quadrant

      The program should continue to calculate the angle correctly.

      This is a good place to think about the difference between an angle and a ratio.

      6. A Trigonometric Pattern#

      Create a program called trig_pattern.js.

      This is the final challenge.

      You are going to draw a shape by generating points in polar coordinates.

      Start at the center of the screen.

      For a sequence of angles:

      0, Δθ, 2Δθ, 3Δθ, ...

      calculate a radius for each angle.

      The radius should change according to a sine or cosine function.

      Then convert the resulting polar coordinates into ordinary screen coordinates.

      Finally, connect consecutive points with lines.

      Requirements#

      Your program should:

      • use an angle that changes steadily;
      • use sine or cosine to calculate a changing radius;
      • calculate (x, y) from (radius, angle);
      • generate many points;
      • connect consecutive points;
      • produce a closed or nearly closed visual pattern;
      • contain no hard-coded list of points.

      Choose constants for:

      • the center of the pattern;
      • the base radius;
      • the amount by which the radius changes;
      • how quickly the radius changes as the angle changes;
      • the number of points.

      The exact shape is up to you.

      For example, you might make the radius grow and shrink several times during one revolution.

      You should be able to change one constant and see the pattern change.

      The important part#

      Do not begin by trying to invent a pretty picture.

      Begin with the geometry.

      For every point, ask:

      1. What is my angle?
      2. What is my radius?
      3. Where is that point in Cartesian coordinates?

      The final picture is just the result of repeating those three steps.

      Once you have something working, experiment.

      What happens if the radius changes once during a revolution?

      What happens if it changes three times?

      What happens if it changes more rapidly?

      What happens if you use cosine instead of sine?

      This is the same circle you studied in the primer. We are simply allowing the distance from the center to change.

      What we are looking for#

      These challenges are deliberately small.

      There is no new Raylib system to learn here. There is no input handling, physics, animation system, or transformation machinery to distract you.

      The challenge is whether you can take the ideas from the trigonometry primer and turn them into coordinates.

      By the end, you should be comfortable moving between:

      • angle → point on a circle
      • point on a circle → coordinates
      • angle → sine/cosine value
      • sine/cosine value → a visual position
      • Cartesian coordinates ↔ polar coordinates
      • coordinates → angle

      If you get stuck on any challenge, don’t immediately ask someone for the formula.

      Go back to the primer.

      Find the picture that represents the thing you are trying to do.

      Then work from the picture.
