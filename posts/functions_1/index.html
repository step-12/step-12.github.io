    Functions in Math

    August 28, 2026
    Math, Functions

    Functions — A Little Bit of Function#

    1. What Is a Function?#

    A function is a rule that takes an input and produces an output.

    For example:

    f(x) = 2x + 3

    Give it 5:

    f(5) = 2(5) + 3
     = 13

    So we can think of a function as:

    input → function → output

    2. Evaluating Functions#

    If:

    f(x) = x² + 1

    then:

    f(2) = 2² + 1
     = 5

    The x is simply replaced by the input.

    Similarly:

    f(3) = 10
f(4) = 17
f(5) = 26

    The expression f(x) describes the function.

    The expression f(3) means we have applied the function to 3.

    3. Functions Can Take Functions’ Outputs#

    Suppose:

    f(x) = 2x
g(x) = x + 3

    We can put the output of one function into another:

    f(g(x))

    First calculate g(x):

    g(x) = x + 3

    Then apply f:

    f(g(x))
= f(x + 3)
= 2(x + 3)
= 2x + 6

    This is called composition.

    We write:

    (f ∘ g)(x) = f(g(x))

    Think:

    x → g → f → result

    4. Order Matters#

    With the same functions:

    f(x) = 2x
g(x) = x + 3

    we have:

    f(g(x)) = 2x + 6

    But:

    g(f(x)) = 2x + 3

    Therefore:

    f(g(x)) ≠ g(f(x))

    In general, function composition is not commutative.

    The order in which we apply functions matters.

    5. Functions Can Have More Than One Input#

    A function need not have just one input.

    For example:

    f(x, y) = x + y

    Then:

    f(2, 3) = 5

    Or:

    g(x, y) = xy

    gives:

    g(4, 5) = 20

    The basic idea remains:

    inputs → function → output

    6. Functions as Mappings#

    There is another way to think about a function.

    Suppose:

    f(x) = x²

    We could write:

    1 → 1
2 → 4
3 → 9
4 → 16

    Or as a table:

    x    f(x)
1     1
2     4
3     9
4    16

    The formula is one way of describing the function.

    The table is another.

    The important thing is the mapping:

    input → output

    7. One Input, One Output#

    There is one rule that must always hold:

    Every input must have exactly one output.

    For example:

    1 → 2
2 → 4
3 → 6

    is a function.

    But:

    1 → 2
1 → 5

    is not.

    The input 1 has two different outputs.

    Different inputs may have the same output, however:

    1 → 5
2 → 5
3 → 7

    is perfectly valid.

    8. Domain and Range#

    The domain is the set of possible inputs.

    The range is the set of outputs produced.

    For example:

    f(x) = x²

    If the domain is:

    {1, 2, 3}

    then:

    1 → 1
2 → 4
3 → 9

    and the range is:

    {1, 4, 9}

    The domain is part of the definition of a function.

    9. Functions Can Be Used to Define Functions#

    Suppose:

    f(x) = x²

    We can define another function using f:

    g(x) = f(x) + 1

    Therefore:

    g(3)
= f(3) + 1
= 9 + 1
= 10

    We can also compose several functions:

    h(x) = f(g(x))

    Functions can therefore be built from other functions.

    10. One Last Thing#

    There is a useful distinction to keep in mind.

    f

    is a function.

    f(5)

    is the result of applying that function to 5.

    If:

    f(x) = 2x + 1

    then:

    f(5) = 11

    So:

    function ≠ result of applying the function

    This distinction will become increasingly useful.

    11. Where Next?#

    We began with:

    input → function → output

    But functions can do more than simply turn numbers into other numbers.

    They can be:

    composed
combined
inverted

    and, perhaps more interestingly, functions themselves can be inputs and outputs.

    There is quite a lot more to functions than f(x) = ....
