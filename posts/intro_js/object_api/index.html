      Iterating over Objects

      October 10, 2026
      Javascript, Objects, Iteration

      Object and Iteration API#

      We have learned about arrays, objects, and loops.

      We know how to describe a thing using an object. We know how to keep a collection of values in an array. And we know how to use loops when we want to repeat an operation.

      JavaScript gives us a few more tools to work with these things.

      In this post, we will learn about:

      • Object.keys
      • Object.values
      • Object.entries
      • for...of
      • for...in

      Nothing complicated. Just a few useful tools to add to our toolbox.

      Object.keys#

      Consider this object:

      const student = {
  name: "Anu",
  age: 20,
  city: "Chennai",
};

      We know how to access a property if we know its name:

      student.name;
student.age;

      But what if we don’t know the property names beforehand?

      What if we want to find out which properties an object has?

      JavaScript gives us Object.keys for this.

      Object.keys(student);

      The result is:

      ["name", "age", "city"];

      Notice that the result is an array.

      Object.keys takes an object and gives us an array containing its property names.

      We can store that array in a variable:

      const keys = Object.keys(student);

console.log(keys);

      We can then use the array just as we would use any other array.

      For example:

      keys[0];
keys[1];
keys.length;

      There is nothing special about the resulting array. It is an ordinary JavaScript array.

      Try it#

      Given the following object:

      const rectangle = {
  width: 100,
  height: 50,
  color: "red",
};

      What will Object.keys(rectangle) return?

      What is the length of the resulting array?

      What happens if you access its first element?

      Make a prediction before running the code.

      Object.values#

      We can get the property names of an object. What if we want the values instead?

      JavaScript gives us Object.values.

      Consider our student again:

      const student = {
  name: "Anu",
  age: 20,
  city: "Chennai",
};

      We can write:

      Object.values(student);

      The result is:

      ["Anu", 20, "Chennai"];

      This time, we get an array containing the property’s values.

      Compare the two:

      Object.keys(student);
// ["name", "age", "city"]

Object.values(student);
// ["Anu", 20, "Chennai"]

      Both produce arrays. But the arrays contain different things.

      Object.keys gives us the property names.

      Object.values gives us the property values.

      Try it#

      Given:

      const rectangle = {
  width: 100,
  height: 50,
  color: "red",
};

      What will Object.values(rectangle) return?

      What is the type of the first element of the resulting array?

      What is the type of the last element?

      Remember that JavaScript objects can contain values of different types.

      Object.entries#

      Sometimes, we want both the property name and its value.

      For example, suppose we want to print:

      name Anu
age 20
city Chennai

      We could write each line separately. But that would be repetitive.

      JavaScript gives us Object.entries.

      Object.entries(student);

      The result is:

      [
  ["name", "Anu"],
  ["age", 20],
  ["city", "Chennai"],
];

      Look carefully at the result.

      It is an array. Each element of that array is itself an array containing two values:

      1. The property name.
      2. The property’s value.

      For example:

      Object.entries(student)[0];
// ["name", "Anu"]

      And:

      Object.entries(student)[1];
// ["age", 20]

      We call these key-value pairs.

      So we now have three related APIs:

      APIWhat it gives us
      Object.keys(obj)An array of property names
      Object.values(obj)An array of property values
      Object.entries(obj)An array of key-value pairs

      These are useful when we want to examine an object without knowing all its property names beforehand.

      for...of#

      We already know how to use a loop to go through an array.

      For example:

      const numbers = [10, 20, 30];

for (let i = 0; i < numbers.length; i++) {
  console.log(numbers[i]);
}

      This prints:

      10
20
30

      Notice what we are doing.

      We keep track of an index. We check whether the index is within the array’s bounds. We access the element at that index.

      This works perfectly well.

      But what if we don’t actually need the index? What if we just want to visit every value?

      JavaScript gives us another kind of loop for this: for...of.

      const numbers = [10, 20, 30];

for (const number of numbers) {
  console.log(number);
}

      This also prints:

      10
20
30

      Let’s look at the syntax:

      for (const number of numbers) {
  console.log(number);
}

      Read it as:

      For each value in numbers, call that value number and execute the body of the loop.

      During the first iteration, number is 10.

      During the second iteration, number is 20.

      During the third iteration, number is 30.

      The loop handles moving from one value to the next. We don’t need to manage an index ourselves.

      The variable declared in the loop receives the value for the current iteration. Here, we use const because we don’t need to reassign number.

      Iterating over strings#

      for...of also works with strings.

      const word = "hello";

for (const character of word) {
  console.log(character);
}

      This prints:

      h
e
l
l
o

      Each iteration gives us the next character.

      We can use for...of with arrays and strings because both provide a sequence of values for the loop to visit.

      For now, remember this:

      Use for...of when you want to iterate over the values of an array.

      Try it#

      Given:

      const fruits = ["apple", "banana", "orange"];

      Write a for...of loop that prints every fruit.

      Then write another loop that prints the length of each fruit’s name.

      Can you do both without using an index?

      Combining Object.keys and for...of#

      We now have two useful tools.

      Object.keys gives us an array of property names.

      for...of lets us iterate over the values in an array.

      What happens when we combine them?

      Consider:

      const student = {
  name: "Anu",
  age: 20,
  city: "Chennai",
};

const keys = Object.keys(student);

for (const key of keys) {
  console.log(key);
}

      This prints:

      name
age
city

      We first obtain the property names as an array. Then we iterate over that array.

      We can simplify this by passing the result of Object.keys directly to the loop:

      for (const key of Object.keys(student)) {
  console.log(key);
}

      Both versions do the same thing.

      Now, we know how to obtain the property names. We also know how to access a property using its name.

      Put those ideas together:

      for (const key of Object.keys(student)) {
  console.log(key, student[key]);
}

      This prints:

      name Anu
age 20
city Chennai

      Notice that we used student[key], not student.key.

      Why?

      Because key is a variable containing the property name. We want to use the value stored in that variable to access the property.

      If key contains "name", then student[key] accesses student.name.

      We have seen this before when learning about objects. Now we have a convenient way to use it with every property of an object.

      for...in#

      There is another loop that looks similar to for...of.

      It is called for...in.

      Let’s look at an example:

      const student = {
  name: "Anu",
  age: 20,
  city: "Chennai",
};

for (const key in student) {
  console.log(key);
}

      This prints:

      name
age
city

      That looks familiar. We got the same property names using Object.keys.

      The difference is that for...in visits the object’s enumerable property names directly. We don’t need to create an array of keys first.

      We can also use the property name to access its value:

      for (const key in student) {
  console.log(key, student[key]);
}

      This prints:

      name Anu
age 20
city Chennai

      The key variable receives a property name during each iteration. We can then use bracket notation to access the corresponding value.

      for...in and arrays#

      There is something important to remember here.

      Consider this array:

      const numbers = [10, 20, 30];

      What do you think happens when we write:

      for (const value of numbers) {
  console.log(value);
}

      We get:

      10
20
30

      Now consider:

      for (const key in numbers) {
  console.log(key);
}

      This ordinarily prints:

      0
1
2

      Why?

      An array has property names corresponding to its indices. for...in visits those names, which are strings in this example.

      for...of, on the other hand, gives us the values at those positions.

      This is an important distinction.

      For arrays, we generally want to work with the elements themselves. Therefore, prefer for...of when iterating over an array.

      for...in is useful when we want to examine an object’s property names.

      One small detail: for...in can also visit enumerable properties inherited through an object’s prototype. The examples in this post use ordinary objects with their own properties, so we don’t need to worry about that just yet.

      Putting it together with Object.entries#

      We have one last useful combination to look at.

      Remember that Object.entries gives us an array of key-value pairs:

      const student = {
  name: "Anu",
  age: 20,
  city: "Chennai",
};

Object.entries(student);

      The result is:

      [
  ["name", "Anu"],
  ["age", 20],
  ["city", "Chennai"],
];

      We already know how to iterate over an array with for...of.

      So we can write:

      for (const entry of Object.entries(student)) {
  console.log(entry);
}

      Each entry is an array containing two elements.

      For example, the first entry is:

      ["name", "Anu"];

      We could access the two elements by their indices:

      for (const entry of Object.entries(student)) {
  const key = entry[0];
  const value = entry[1];

  console.log(key, value);
}

      But remember that we have already learned about destructuring.

      We can use it here:

      for (const [key, value] of Object.entries(student)) {
  console.log(key, value);
}

      This does the same thing.

      During each iteration, the pair is destructured into two variables: key and value.

      The first iteration gives us "name" and "Anu".

      The second gives us "age" and 20.

      The third gives us "city" and "Chennai".

      This is a useful pattern to recognize. You will encounter it often when working with objects.

      What should you use?#

      We have learned several ways to work with objects and arrays. Which one should we choose?

      Here are some simple guidelines.

      • Use Object.keys(obj) when you want an array of an object’s property names.
      • Use Object.values(obj) when you want an array of its property values.
      • Use Object.entries(obj) when you want an array of key-value pairs.
      • Use for...of when you want to iterate over the values of an array or the characters of a string.
      • Use for...in when you want to iterate over an object’s enumerable property names.

      Remember that the three Object APIs return arrays containing an object’s own enumerable properties. for...in can also include inherited enumerable properties.

      You don’t need to memorize every detail today. What matters is understanding what each tool gives you and knowing when it is useful.

      Exercises#

      1. Predict the output#

      Without running the code, predict what will be printed.

      const book = {
  title: "The Hobbit",
  year: 1937,
  available: true,
};

console.log(Object.keys(book));
console.log(Object.values(book));
console.log(Object.entries(book));

      2. Print the property names#

      Given:

      const rectangle = {
  width: 100,
  height: 50,
  color: "red",
};

      Write a loop that prints each property name on a separate line.

      3. Print the property names and values#

      Using the same rectangle object, print each property name followed by its value.

      For example:

      width 100
height 50
color red

      Try solving this first with Object.keys and for...of. Then try it with for...in.

      4. Sum the values#

      Given:

      const scores = {
  Anu: 10,
  Rahul: 20,
  Meera: 30,
};

      Use Object.values and a loop to calculate the total score.

      Do not change the original object.

      5. Count the properties#

      Write a program that uses Object.keys to find out how many properties the following object has:

      const device = {
  brand: "Acme",
  model: "X1",
  year: 2025,
  working: true,
};

      6. Iterate over an array#

      Given:

      const numbers = [10, 20, 30, 40, 50];

      Write two loops:

      1. A for...of loop that prints every number.
      2. A for...in loop that prints every property name it visits.

      Explain why the outputs differ.

      7. Work with entries#

      Given:

      const prices = {
  apple: 20,
  banana: 10,
  orange: 15,
};

      Use Object.entries and for...of to print each fruit and its price.

      Use destructuring to obtain the name and price in each iteration.

      8. Find the most expensive item#

      Given:

      const prices = {
  apple: 20,
  banana: 10,
  orange: 15,
  mango: 40,
};

      Find the name of the most expensive item and its price.

      Use Object.entries and a loop. Do not write separate comparisons for each fruit.

      9. Choose the right tool#

      For each task, choose the most appropriate API or loop and explain your choice.

      1. Print every element of an array.
      2. Get an array containing the property names of an object.
      3. Print both the property names and values of an object.
      4. Get an array containing only the values of an object’s properties.
      5. Visit the property names of an object without first creating an array of keys.

      10. A final challenge#

      Given:

      const inventory = {
  pencils: 12,
  notebooks: 5,
  erasers: 8,
};

      Write a program that prints each item and its quantity, followed by the total quantity of all items.

      Your output should look like this:

      pencils 12
notebooks 5
erasers 8
total 25

      Try to solve this using Object.entries and for...of.
