    JavaScript Practice#

    Solve the following problems in JavaScript.

    You have not learned traditional loops yet, so do not use for, while, or similar loops. Use recursion whenever you need to repeat an operation.

    Write a separate function for each problem.

    1. Simple Interest#

    Write a function that calculates simple interest.

    The function should take:

    • principal amount
    • rate of interest
    • time

    and return the simple interest.

    For example:

    simpleInterest(1000, 5, 2) → 100

    2. Compound Interest#

    Write a function that calculates compound interest.

    The function should take:

    • principal amount
    • rate of interest
    • number of years

    and return the compound interest.

    For example, if ₹1000 is invested at 10% per year for 2 years, the final amount is ₹1210.

    3. Print Even Numbers#

    Write a function that prints all the even numbers from 1 up to a given number.

    For example:

    printEvenNumbers(10)

2
4
6
8
10

    4. Decimal to Binary#

    Write a function that converts a positive decimal integer into its binary representation.

    For example:

    decimalToBinary(10) → 1010
decimalToBinary(7)  → 111
decimalToBinary(16) → 10000

    5. Factorial#

    Write a function that calculates the factorial of a number.

    For example:

    factorial(5) → 120

    Remember:

    5! = 5 × 4 × 3 × 2 × 1

    6. Nth Fibonacci Term#

    Write a function that returns the nth term of the Fibonacci sequence.

    Use this definition:

    F(0) = 0
F(1) = 1

F(n) = F(n - 1) + F(n - 2)

    For example:

    fibonacci(0) → 0
fibonacci(1) → 1
fibonacci(6) → 8

    7. Fibonacci Series#

    Write a function that prints the first n terms of the Fibonacci sequence.

    For example:

    fibonacciSeries(7)

0
1
1
2
3
5
8

    8. Is Prime?#

    Write a function that determines whether a number is prime.

    For example:

    isPrime(7)  → true
isPrime(12) → false

    A prime number is a number greater than 1 that has no divisors other than 1 and itself.

    9. Find All Primes#

    Write a function that prints all prime numbers between 1 and a given number.

    For example:

    findAllPrimes(10)

2
3
5
7

    You will need to make use of your isPrime function.

    10. First Prime Above#

    Write a function that finds the first prime number greater than a given number.

    For example:

    firstPrimeAbove(10) → 11
firstPrimeAbove(20) → 23

    11. HCF#

    Write a function that finds the Highest Common Factor (HCF) of two numbers.

    For example:

    hcf(12, 18) → 6
hcf(20, 30) → 10

    12. LCM#

    Write a function that finds the Least Common Multiple (LCM) of two numbers.

    For example:

    lcm(4, 6) → 12
lcm(5, 7) → 35

    13. Armstrong Number#

    Write a function that determines whether a number is an Armstrong number.

    For a three-digit number, an Armstrong number is a number whose value is equal to the sum of the cubes of its digits.

    For example:

    153 = 1³ + 5³ + 3³

    Therefore, 153 is an Armstrong number.

    Your function should return true or false.

    14. Palindrome#

    Write a function that determines whether a number is a palindrome.

    A palindrome reads the same forwards and backwards.

    For example:

    121 → true
123 → false

    15. Leap Year#

    Write a function that determines whether a given year is a leap year.

    For example:

    isLeapYear(2024) → true
isLeapYear(2023) → false

    16. Prime Factors#

    Write a function that prints all the prime factors of a number.

    For example:

    primeFactors(12)

2
2
3

    Another example:

    primeFactors(60)

2
2
3
5

    17. Square Root#

    Write a function that calculates the square root of a number.

    Do not use Math.sqrt().

    For example:

    squareRoot(25) → 5
squareRoot(49) → 7

    Think carefully about how you could approximate the answer when the number is not a perfect square.

    18. Sum of an Arithmetic Progression#

    Write a function that calculates the sum of the first n terms of an arithmetic progression.

    The function should take:

    • the first term
    • the common difference
    • the number of terms

    For example:

    sumOfAP(2, 3, 5) → 40

    because:

    2 + 5 + 8 + 11 + 14 = 40
