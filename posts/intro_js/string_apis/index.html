      String APIs

      November 19, 2026
      Javascript, Strings, Apis

      Working with Strings#

      We’ve learned that strings are another kind of value in JavaScript.

      We can write strings:

      const message = "Hello World";

      We can combine them:

      "Hello" + " World";

      And we can put expressions inside them using template strings:

      const name = "Anu";

`Hello ${name}`;

      So far, we’ve mostly treated strings as complete pieces of text.

      But what happens when we want to work with only a part of a string?

      What if we want to check whether a string contains a particular word?

      We could write our own logic for all these operations.

      But JavaScript already provides ways to do them.

      Let’s explore some of them.

      Changing letter case#

      Imagine we have the following values:

      const name = "Charan";
const city = "BANGALORE";

      What if we want to convert the name to uppercase?

      Or convert the city to lowercase?

      We could manually write every letter again, but that would become inconvenient.

      JavaScript provides two APIs for this.

      toUpperCase()#

      Try:

      "hello".toUpperCase();

      What did you get?

      Now try:

      "hello world".toUpperCase();

      All the lowercase letters have become uppercase.

      We can also use it with a variable:

      const name = "Charan";

name.toUpperCase();

      toLowerCase()#

      What if we want the opposite?

      Try:

      "HELLO".toLowerCase();

      And:

      "Hello World".toLowerCase();

      All the uppercase letters have become lowercase.

      Notice something interesting.

      These APIs don’t change the original string.

      Try:

      const name = "Charan";

name.toUpperCase();

name;

      What did you get?

      The original value is still "Charan".

      If we want to keep the converted value, we need to assign it:

      const upperName = name.toUpperCase();

      Remember:

      • toUpperCase() converts letters to uppercase.
      • toLowerCase() converts letters to lowercase.
      • Both produce a new string.

      Try it#

      1. Convert "javascript" to uppercase.
      2. Convert "WELCOME TO STEP-12" to lowercase.

      Checking text#

      Imagine we’re building a program that works with filenames.

      We receive a filename:

      const filename = "photo.png";

      We want to check whether the filename ends with .png.

      Or imagine we’re checking a username:

      const username = "step12_charan";

      We want to check whether it starts with "step12".

      We could write logic to examine individual characters.

      But JavaScript already provides APIs for checking these things.

      startsWith()#

      Try:

      "photo.png".startsWith("photo");

      What did you get?

      Now try:

      "photo.png".startsWith("png");

      What happened?

      startsWith() checks whether a string begins with the text we provide.

      It produces a boolean value:

      • true if the string starts with the given text.
      • false otherwise.

      Let’s try another example:

      const username = "step12_charan";

username.startsWith("step12");

      endsWith()#

      Similarly, what if we want to check how a string ends?

      Try:

      "photo.png".endsWith(".png");

      And:

      "photo.png".endsWith(".jpg");

      endsWith() checks whether a string ends with the given text.

      This can be useful when checking file extensions.

      includes()#

      Now consider another situation.

      We have a message:

      const message = "Welcome to STEP-12 JavaScript";

      We want to check whether the message contains the word "JavaScript".

      The word doesn’t necessarily have to appear at the beginning or end.

      We just want to know whether it exists somewhere inside the string.

      Try:

      message.includes("JavaScript");

      Now try:

      message.includes("Python");

      includes() checks whether a string contains the given text.

      It also produces a boolean value.

      Notice the difference:

      • startsWith() checks the beginning.
      • endsWith() checks the end.
      • includes() checks anywhere inside the string.

      Try it#

      1. Check whether "javascript.js" starts with "java".
      2. Check whether "image.jpeg" ends with ".png".
      3. Check whether "Welcome to STEP-12" includes "STEP".

      Finding characters and text#

      Let’s say we have a string:

      const language = "JavaScript";

      What if we want to know where the letter "S" appears?

      Or what if we want to get the character at a particular position?

      Let’s explore.

      indexOf()#

      Try:

      "JavaScript".indexOf("S");

      What did you get?

      Now try:

      "JavaScript".indexOf("a");

      Notice that JavaScript gives us a number.

      It tells us the position where the given text first appears.

      Remember that string positions start from 0.

      Let’s look at the positions:

      CharacterJavaScript
      Position0123456789

      So:

      "JavaScript".indexOf("S");

      produces 4.

      What happens if the given text doesn’t exist?

      Try:

      "JavaScript".indexOf("z");

      You get -1.

      This is important.

      indexOf() returns -1 when it cannot find the given text.

      at()#

      Now that we know how string positions work, let’s try accessing a character directly.

      Try:

      const language = "JavaScript";

language.at(0);

      What did you get?

      Now try:

      language.at(4);

      We get the character at the requested position.

      But here’s something interesting.

      Try:

      language.at(-1);

      What happened?

      It gives us the last character!

      Try:

      language.at(-2);

      It gives us the second-last character.

      This is useful when we want to access characters from the end without calculating their positions ourselves.

      Try it#

      1. Find the position of "p" in "JavaScript".
      2. Find the position of "z" in "JavaScript".
      3. Get the first character of "STEP-12".
      4. Get the last character of "STEP-12".

      Taking a portion of a string#

      Consider the following string:

      const message = "Welcome to STEP-12";

      What if we only want "STEP-12"?

      We could manually create another string.

      But what if the string changes?

      Or what if we want to extract different portions of it?

      JavaScript provides an API for this.

      slice()#

      Try:

      message.slice(11);

      What did you get?

      We got everything starting from position 11 until the end of the string.

      But what if we don’t want everything until the end?

      We can provide another position.

      Try:

      message.slice(11, 15);

      What happened?

      We got the characters from position 11 up to position 15.

      Notice something important.

      The starting position is included, but the ending position is not included.

      Let’s look at another example:

      "JavaScript".slice(0, 4);

      We get:

      "Java"

      Why?

      Because JavaScript takes positions 0, 1, 2, and 3.

      It stops before position 4.

      We can also use negative positions.

      Try:

      "JavaScript".slice(-6);

      What did you get?

      It starts six characters from the end and takes everything after that.

      Remember:

      • slice(start) takes text from the starting position until the end.
      • slice(start, end) takes text from the starting position up to, but not including, the ending position.
      • Negative positions count from the end.

      Try it#

      Given:

      const language = "JavaScript";
      1. Extract "Java" using slice().
      2. Extract "Script" using slice().
      3. Extract the last three characters.

      Combining strings#

      We’ve already seen that we can combine strings using the + operator.

      For example:

      "Hello" + " World";

      JavaScript also provides an API for combining strings.

      concat()#

      Try:

      "Hello".concat(" World");

      What did you get?

      We can also combine more than two strings.

      Try:

      "Hello".concat(" ", "STEP-12", "!");

      The result is:

      "Hello STEP-12!"

      Notice that concat() produces a new string.

      It doesn’t change the original string.

      We can also achieve the same result using the + operator or template strings.

      For example:

      const firstName = "Anu";
const lastName = "Kumar";

firstName + " " + lastName;

      Or:

      `${firstName} ${lastName}`;

      There are multiple ways to combine strings in JavaScript.

      repeat()#

      Now imagine we want to print a line of dashes:

      "----------";

      What if we want 50 dashes?

      Writing all 50 characters manually isn’t very convenient.

      Try:

      "-".repeat(10);

      What did you get?

      It repeats the original string the requested number of times.

      Try:

      "Hello ".repeat(3);

      And:

      "STEP-12 ".repeat(5);

      Notice that repeat() doesn’t add anything new to the string.

      It simply repeats what already exists.

      Try it#

      1. Combine "STEP" and "12" using concat().
      2. Combine your first name and last name using concat().
      3. Repeat "*" 20 times.
      4. Repeat "Hello " 5 times.

      Formatting strings#

      Imagine we’re generating student IDs.

      We have:

      const studentId = "42";

      But we want every ID to contain 5 characters.

      For example:

      00042

      We could manually add zeros.

      But what if the ID is 7 or 123?

      We would need to calculate how many zeros to add.

      JavaScript provides two APIs that can help.

      padStart()#

      Try:

      "42".padStart(5, "0");

      What did you get?

      We get:

      "00042"

      What is happening here?

      • The original string has 2 characters.
      • We want the final string to have 5 characters.
      • JavaScript adds "0" to the beginning until the required length is reached.

      Try:

      "7".padStart(5, "0");

      And:

      "123".padStart(5, "0");

      Notice that the padding adjusts automatically.

      padEnd()#

      What if we want to add characters at the end instead?

      Try:

      "42".padEnd(5, "0");

      We get:

      "42000"

      The difference is simple:

      • padStart() adds characters at the beginning.
      • padEnd() adds characters at the end.

      We can also use other characters.

      Try:

      "STEP".padEnd(10, "-");

      And:

      "STEP".padStart(10, "*");

      One more thing to notice.

      The first argument is the total desired length, not the number of characters to add.

      Try it#

      1. Convert "9" into a 4-character string using padStart() and "0".
      2. Convert "STEP" into an 8-character string using padEnd() and "*".
      3. Convert "25" into a 6-character string using padStart() and "-".

      Removing unwanted spaces#

      Consider the following value:

      const username = "  charan  ";

      Notice that there are spaces before and after the username.

      What if these spaces were accidentally entered by someone?

      We probably don’t want to keep them.

      We could manually check the beginning and end of the string and remove those spaces.

      But JavaScript already provides APIs for this.

      trim()#

      Try:

      "  charan  ".trim();

      What did you get?

      The spaces at the beginning and end are removed.

      Notice that the spaces between words are not removed.

      Try:

      "  Hello World  ".trim();

      The result is:

      "Hello World"

      trimStart()#

      What if we only want to remove spaces from the beginning?

      Try:

      "  Hello World  ".trimStart();

      The spaces at the beginning are removed, but the spaces at the end remain.

      trimEnd()#

      And what if we only want to remove spaces from the end?

      Try:

      "  Hello World  ".trimEnd();

      The spaces at the end are removed, but the spaces at the beginning remain.

      Remember:

      • trim() removes whitespace from both ends.
      • trimStart() removes whitespace from the beginning.
      • trimEnd() removes whitespace from the end.

      These APIs remove whitespace, not just ordinary spaces.

      And just like the other string APIs we’ve explored, they return a new string.

      The original string remains unchanged.

      Try it#

      1. Remove unwanted spaces from both ends of " STEP-12 ".
      2. Remove only the beginning spaces from " JavaScript".
      3. Remove only the ending spaces from "JavaScript ".

      Splitting strings#

      Imagine we have a sentence:

      const message = "Welcome to STEP-12";

      What if we want to get each word separately?

      We could manually find where each word starts and ends.

      But JavaScript provides an API for this.

      split()#

      Try:

      "Welcome to STEP-12".split(" ");

      What did you get?

      We get:

      ["Welcome", "to", "STEP-12"]

      Notice that the string has been broken into smaller pieces wherever a space appears.

      Each piece becomes an individual item in an array.

      We can also split using other characters.

      Try:

      "apple,banana,orange".split(",");

      We get:

      ["apple", "banana", "orange"]

      What if we want to split the string into individual characters?

      Try:

      "STEP".split("");

      We get:

      ["S", "T", "E", "P"]

      The value we pass to split() tells JavaScript where to break the string.

      split() doesn’t modify the original string. It returns a new array.

      Try it#

      1. Split "Hello World" into individual words.
      2. Split "red,green,blue" wherever a comma appears.
      3. Split "JavaScript" into individual characters.

      A final thought#

      We’ve just explored several APIs that JavaScript provides for working with strings.

      You might have noticed something interesting.

      We could write our own logic to perform many of these operations.

      For example, we could manually examine characters to check whether a string starts with a particular word.

      We could write loops to repeat a string.

      We could manually remove unwanted spaces.

      But these APIs already provide ways to perform those operations.

      As you write more programs, you’ll encounter situations where you need to work with text.

      As you learn more APIs, you’re also building something important: a vocabulary to solve problems.

      The more APIs you explore, the more familiar you’ll become with the operations available to you.

      This vocabulary helps you recognize problems, think about possible solutions, and choose the right tools instead of writing everything from scratch.

      The important thing isn’t remembering every API.

      It’s recognizing the problem you’re trying to solve and knowing that JavaScript might already provide a way to solve it.
