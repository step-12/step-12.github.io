    IDE (VSCode)

    September 18, 2026
    VSCode

    IDE#

    IDE stands for Integrated Development Environment.

    An IDE is a development environment that brings together the tools needed to write, understand, run, and debug software. It provides a graphical interface that coordinates these tools and makes software development easier.

    An IDE helps you:

    • Navigate code
    • Write and edit code
    • Run code
    • Debug code
    • Search and replace text
    • Manage files and folders
    • Integrate with version control
    • Install extensions for additional functionality

    For this lesson, we will use VS Code as an example of an IDE.

    IDE vs Terminal#

    We have already seen that when we launch a terminal, it starts a process. Does launching an IDE also create a process?

    Let’s look at the process tree of VS Code:

    As you can see, VS Code also runs as a process. In fact, it launches multiple processes to handle different responsibilities.

    Why so many processes?#

    When you open VS Code, its main process acts as a manager. It launches different processes, each responsible for a specific job, such as:

    • Displaying the user interface
    • Handling network requests
    • Running extensions
    • Processing background tasks
    • Managing files and other services

    Just as a shell can launch multiple processes, VS Code’s main process can also launch multiple child processes.

    Key takeaway: An IDE is not just a window on the screen. Like a terminal, it is backed by processes that perform the work. The graphical interface is one way of interacting with those processes.

    VSCode is a browser. But how?#

    If we look closely at VS Code, it looks quite similar to a browser. It allows us to open files in different tabs, switch between them, and interact with different views.

    This similarity exists because VS Code uses technologies associated with web applications to build its user interface. It is built on Electron, a framework that allows developers to create desktop applications using web technologies.

    However, VS Code is not simply a browser. It is a desktop application designed for software development. It combines a user interface with capabilities such as file management, code editing, debugging, terminal integration, and extension support.

    A useful comparison#

    BrowserVS Code
    Opens and displays web pagesOpens and displays code files
    Uses tabs to switch between pagesUses tabs to switch between files
    Has a user interface for interacting with web contentHas a user interface for interacting with code and development tools
    Runs web applicationsRuns development tools and extensions

    To explore this further, run pstree on Chrome and compare its process tree with the process tree of VS Code.

    Think about: Both applications have a main process and supporting processes. What responsibilities might those supporting processes have?

    Where Do the Changes Go?#

    When you edit a file in VS Code, your changes are initially made in the editor. They are written to the actual file on disk when you save the file.

    By default, you can save a file using cmd+s.

    VS Code also supports Auto Save, which can save changes automatically based on the configured setting. For example, when Auto Save is set to onFocusChange, the file is saved when the editor loses focus.

    Important: Editing a file and saving a file are two different actions. Editing changes the content in the editor, while saving writes those changes to the file on disk.

    Sections of an IDE#

    Most IDEs provide several common sections that help developers work with code. In VS Code, three primary sections are:

    1. Editor — The area where you write and edit code.
    2. File Explorer — The area where you browse and manage files and folders.
    3. Terminal — The area where you interact with the shell and run commands.

    Different IDEs may organize these sections differently or provide additional sections, such as:

    • Source Control — To manage Git changes and version control.
    • Run and Debug — To run applications and inspect their execution.
    • Extensions — To install and manage extensions.
    • Search — To search across files in a project.

    VS Code Settings#

    VS Code provides many settings to customize the editor according to your preferences. You can open Settings using ⌘ + , and search for a specific setting.

    Turn on Auto Save#

    1. Press ⌘ + , to open Settings.
    2. Search for “auto save”.
    3. Change the value in the drop-down menu to onFocusChange.

    Turn off Auto Update#

    1. Press ⌘ + , to open Settings.
    2. Search for “auto update”.
    3. Change the value to off.

    Increase Font Size to 18#

    1. Press ⌘ + , to open Settings.
    2. Search for “font size”.
    3. Change the value to 18.

    Hide the Minimap#

    The minimap displays a small visual overview of the code on the side of the editor.

    To hide it:

    1. Right-click on the minimap.
    2. Untick Minimap.

    Move the Sidebar to the Right (Optional)#

    You can move the primary sidebar to the right if that layout is more comfortable for you.

    1. Right-click on the sidebar.
    2. Click Move Primary Side Bar Right.
