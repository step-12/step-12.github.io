      Lint and Lint Errors

      November 24, 2026
      Javascript, Lint, Style

      What is lint?#

      Suppose you write this program:

      const total = 10 + 20;
console.log("Done");

      Run it. You will see:

      Done

      The program works. But look at total.

      You calculated it and never used it. Perhaps you meant to print it. Perhaps you no longer need that line.

      JavaScript does not complain, so how would you notice?

      We can use a tool to examine the code we have written.

      It does not run the program. Instead, it checks the code against a set of rules to identify potential problems , expected style which we are supposed to write programs in and code-quality issues.

      For example, a rule might ask:

      Did you create a variable and never use it?

      Another might ask:

      Did you use a name that was never defined?

      Some rules help catch mistakes. Others help us write code that is easier to read.

      These small issues identified in our code are called lint.

      The tool that checks for them is called a linter.

      When we use it to check our code, we are linting.

      If our code breaks a rule, the tool reports a lint error or a lint warning.

      Our unused total is one example. The program runs, but the linter still has something useful to tell us.

      The name comes from everyday English, where lint refers to tiny pieces of fluff found on clothes. Just as we remove unwanted fluff from our clothes, linting helps us identify and clean up unwanted issues in our code.

      Below, each topic has one example that causes a lint error and one way to fix it.

      Variables and names#

      A variable you never use#

      If you declare a variable but never use it, remove it or use it.

      Lint error:

      const total = 10 + 20;

      Fix:

      const total = 10 + 20;
console.log(total);

      A name JavaScript does not know#

      Declare a name before using it, and check that you have spelled it correctly.

      Lint error:

      console.log(totle);

      Fix:

      const total = 30;
console.log(total);

      Declaring the same name twice#

      Do not declare the same name twice in the same scope.

      Lint error:

      var score = 10;
var score = 20;

      Fix:

      let score = 10;
score = 20;

      Reusing a name inside a function#

      Give an inner variable a different name from a variable outside it.

      Lint error:

      const score = 10;
function showScore(score) {
  console.log(score);
}

      Fix:

      const score = 10;
function showScore(currentScore) {
  console.log(currentScore);
}

      Using var#

      Use let or const instead of var.

      Lint error:

      var count = 0;

      Fix:

      const count = 0;

      Using let when the value never changes#

      Use const when you never assign a new value to a variable.

      Lint error:

      let width = 800;

      Fix:

      const width = 800;

      Using a name before defining it#

      Define a name before the line where you use it.

      Lint error:

      console.log(total);
const total = 30;

      Fix:

      const total = 30;
console.log(total);

      Trying to change a constant#

      Do not assign a new value to a variable declared with const.

      Lint error:

      const score = 10;
score = 20;

      Fix:

      let score = 10;
score = 20;

      Creating a global name#

      In a browser script, a name written outside a block can become available everywhere, so keep it inside a block or function.

      Lint error:

      var score = 10;

      Fix:

      {
  const score = 10;
  console.log(score);
}

      Assigning undefined for no reason#

      Leave an uninitialized variable alone instead of assigning it undefined.

      Lint error:

      let result = undefined;

      Fix:

      let result;

      Writing a name with underscores#

      Use camelCase for names such as totalPrice.

      Lint error:

      const total_price = 30;

      Fix:

      const totalPrice = 30;

      Functions and decisions#

      An empty function#

      Give a function something to do, or remove it if you do not need it.

      Lint error:

      function showMessage() {}

      Fix:

      function showMessage() {
  console.log("Hello");
}

      Changing a function input#

      Return a new value instead of assigning one to a function parameter.

      Lint error:

      function addOne(number) {
  number = number + 1;
  return number;
}

      Fix:

      function addOne(number) {
  return number + 1;
}

      Putting too many choices in one line#

      If one ? : choice sits inside another, use if statements to make the choices easier to read.

      Lint error:

      const label = score > 80 ? "high" : score > 40 ? "middle" : "low";

      Fix:

      let label;
if (score > 80) {
  label = "high";
} else if (score > 40) {
  label = "middle";
} else {
  label = "low";
}

      Using else after return#

      After an if branch returns, write the next return without else.

      Lint error:

      function sign(number) {
  if (number > 0) {
    return "positive";
  } else {
    return "not positive";
  }
}

      Fix:

      function sign(number) {
  if (number > 0) {
    return "positive";
  }
  return "not positive";
}

      Leaving out braces#

      Put braces around every if, else, and loop body.

      Lint error:

      if (isReady) console.log("Start");

      Fix:

      if (isReady) {
  console.log("Start");
}

      Code that will never run#

      Remove code that cannot run, such as a statement after return.

      Lint error:

      function double(number) {
  return number * 2;
  console.log("Done");
}

      Fix:

      function double(number) {
  console.log("Done");
  return number * 2;
}

      Comparing a value with itself#

      Do not compare a value with itself; compare the values you meant to check.

      Lint error:

      score === score;

      Fix:

      score === targetScore;

      Using == instead of ===#

      Use === and !== instead of == and !=; this rule allows == null.

      Lint error:

      count == 0;

      Fix:

      count === 0;

      Numbers#

      A number with no explanation#

      Give meaningful numbers a name; this setup allows -1, 0, 1, array indexes, and default parameter values.

      Lint error:

      const total = price * 1.18;

      Fix:

      const taxMultiplier = 1.18;
const total = price * taxMultiplier;
