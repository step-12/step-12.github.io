    Simple exercises

    September 23, 2026
    Raylib, Graphics

    First Exercises#

    You now have a working Raylib program.

    You have seen how a Raylib program is structured, and you have used functions such as r.DrawRectangle.

    Now it is time to start solving some small problems.

    For these exercises, create a directory called:

    workspace/raylib_exercises/

    Each exercise should be its own program.

    Use these filenames:

    01_center_rectangle.js
02_center_rectangle_in_rectangle.js
03_scale_and_center.js
04_closer_target.js

    Write the Raylib program yourself for each exercise. You should not need to copy the program from the previous post.

    Exercise 1: Center a Rectangle#

    Create a window and draw a rectangle.

    Give the rectangle a width and a height.

    Your task is to make the rectangle appear exactly in the centre of the window.

    Think carefully about what “centre” means.

    What do you know about the window?

    What do you know about the rectangle?

    Where should the rectangle begin?

    Try changing the width and height of the rectangle.

    Try changing the dimensions of the window.

    Does your program still centre the rectangle?

    Now write a function that performs the calculation needed to position the rectangle.

    What should this function receive?

    What should it return?

    Can the same function be used to determine both the horizontal and vertical position?

    Exercise 2: Center a Rectangle Inside Another Rectangle#

    Create two rectangles.

    Give them different colours.

    One rectangle should be larger than the other.

    Your task is to place the smaller rectangle exactly in the centre of the larger rectangle.

    The larger rectangle does not have to be centred in the window.

    Try moving it around.

    Try changing its width and height.

    Try changing the dimensions of the smaller rectangle.

    Does the smaller rectangle remain centred?

    Look at the function you wrote for the previous exercise.

    Can you use it here?

    Exercise 3: Scale and Center#

    Create an outer rectangle.

    This time, don’t specify the dimensions of the inner rectangle directly.

    Instead, specify how large the inner rectangle should be relative to the outer rectangle.

    For example:

    width  = 0.8
height = 0.8

    This should mean that the inner rectangle is 80% as wide and 80% as tall as the outer rectangle.

    Calculate the dimensions of the inner rectangle and place it in the centre of the outer rectangle.

    Try different values.

    What happens at 0.5?

    What happens at 0.25?

    What happens at 1?

    What happens at a value greater than 1?

    What parts of this problem are different from the previous exercise?

    What parts are exactly the same?

    Exercise 4: Find the Closer Target#

    Draw a circle to represent a source.

    Then draw two targets at different positions.

    The source and both targets should be visible on the screen.

    Your task is to determine which target is closer to the source.

    Draw a line from the source to the closer target.

    You may want to look back at the r.DrawLine function from the previous post.

    How can you determine the distance between two points?

    What information do you need about each point?

    What happens if you move the source?

    What happens if you move either target?

    Does your program continue to choose the correct target?

    Try several different arrangements of the three points.

    What happens when the two targets are the same distance from the source?

    Exercise 5: Intersecting Circles#

    Create two circles at different positions and with different radii.

    Your task is to determine whether the two circles intersect.

    • If the circles intersect, colour both circles red.
    • If the circles do not intersect, colour both circles black.
    • Try different positions for the circles.
    • Try different radii.
    • Try cases where the circles are just touching.
    • Try cases where one circle is completely inside the other.

    What information about the two circles do you need in order to determine whether they intersect?

    Can you express the test for intersection as a function?

    What should the function receive?

    What should it return?

    Try changing the positions and radii after your function is working. Does it continue to give the correct result? (step-12.github.io)

    Keep experimenting#

    These programs are deliberately small.

    Don’t rush through them.

    Change the numbers.

    Move things around.

    Try values you did not expect to work.

    But also look carefully at the structure of your programs.

    As you write more functions, ask yourself:

    Does this function do one thing?

    Does its name tell me what it does?

    Does it receive the information it needs as arguments?

    Does it return a useful value rather than changing something somewhere else?

    Am I repeating a calculation that could belong in a function?

    If I change something in one place, will I have to change it in several other places?

    Good programs are not just programs that produce the right answer.

    The way we organise the computation matters too.

    For now, don’t worry about finding the “perfect” structure.

    Write the program.

    Get it working.

    Then look at it again.

    Can you make the functions clearer?

    Can you make them easier to reuse?

    Can you make the next person reading the program understand what each function is responsible for?

    These are questions we will keep returning to.
