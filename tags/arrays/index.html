        Peaks

        October 11, 2026
        Javascript, Raylib, Arrays, Graphs

        Peaks#

        A peak is a value that is greater than the values immediately before and after it.

        Your task is to detect peaks in an array of numbers and draw a line chart that highlights them.

        Reference output

        Requirements#

        • Create an array of numbers yourself. Start with fixed values so you can reason about the expected output. Once your program is working, experiment with randomly generated data.
        • Draw a line chart representing the values in your array.
        • Identify peaks and highlight them with red circles.
        • A value is a peak only if it is strictly greater than both its immediate neighbours. The first and last elements cannot be peaks. Equal values and plateaus do not count as peaks.
        • Determine the horizontal and vertical scales from the data and the dimensions of the screen.
        • Scale the vertical axis so that the maximum value maps to 90% of the screen height.
        • Calculate the horizontal spacing of the data points appropriately. Each point must occupy at least one pixel horizontally. If the data exceeds the available screen width, it is truncated.
        • Allow the screen width and height to be configured.
        • Use only the following colours: r.SKYWHITE, r.BLACK, and r.RED.

        Before you begin#

        Resist the temptation to start writing code immediately.

        Averages

        October 11, 2026
        Javascript, Raylib, Arrays, Graphs

        Averages#

        In this assignment, you will draw a bar chart representing an array of numbers. You will also draw a horizontal line representing the average of those numbers.

        Requirements#

        • The screen width and height must be configurable.
        • The width of each bar must be configurable. It must not be less than 1.
        • The gap between consecutive bars must be configurable.
        • The horizontal and vertical scales must be determined by the data.
        • The largest value in the array must correspond to 90% of the screen height. Use the same vertical scale for every value.
        • If the bars extend beyond the screen width, the excess data may be truncated.
        • Draw the bars in r.DARKBLUE.
        • Draw the average as a horizontal line in r.RED.
        • Use r.SKYWHITE for the background.

        More Array APIs#

        We have learned how arrays work.

        We know how to access an element using its index:

        const numbers = [10, 20, 30];

numbers[1]; // 20

        We know how to move through an array using a loop. We also know how to add and remove elements using APIs such as push, pop, shift, and unshift.

        JavaScript gives us several more useful array APIs. They give names to common operations and save us from writing the same loops repeatedly.

        Arrays#

        So far, we have learned how to describe a thing using an object.

        const student = {
  name: "Anu",
  age: 20,
  city: "Chennai",
};

        This works very well when we have one thing.

        But what happens when we have many things?

        Suppose we have three students:

        const student1 = {
  name: "Anu",
  age: 20,
};

const student2 = {
  name: "Rahul",
  age: 19,
};

const student3 = {
  name: "Meera",
  age: 20,
};

        What if we have thirty students?

        What if we have three hundred?

        We could keep giving every student a different variable name. But something feels wrong about that.
