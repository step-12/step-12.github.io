      Quiz#

      Counting#

      We explored the basics of counting, starting with a simple question: what is a digit?

      We then considered how many numbers can be represented using ten fingers. This led to a thought experiment: if a crow with six fingers joined the count, how many numbers could we represent?

      From there, the discussion introduced the idea of placeholder counting and how a count can be represented using binary.
