        Object and Iteration API#

        We have learned about arrays, objects, and loops.

        We know how to describe a thing using an object. We know how to keep a collection of values in an array. And we know how to use loops when we want to repeat an operation.

        JavaScript gives us a few more tools to work with these things.

        In this post, we will learn about:

        • Object.keys
        • Object.values
        • Object.entries
        • for...of
        • for...in

        Nothing complicated. Just a few useful tools to add to our toolbox.

        Switch Case

        October 9, 2026
        Javascript, Switch/Case, Conditions

        Switch / Case#

        So far, we have used if and else to make decisions in our programs.

        For example:

        const day = 3;

if (day === 1) {
  console.log("Monday");
} else if (day === 2) {
  console.log("Tuesday");
} else if (day === 3) {
  console.log("Wednesday");
} else if (day === 4) {
  console.log("Thursday");
} else if (day === 5) {
  console.log("Friday");
}

        There is nothing wrong with this program.

        But look at what we are doing.

        We keep asking the same kind of question:

        Is day equal to this particular value?

        First:

        day === 1

        Then:

        day === 2

        Then:

        day === 3

        And so on.

        What if JavaScript gave us a construct specifically for this situation?

        Arrays#

        So far, we have learned how to describe a thing using an object.

        const student = {
  name: "Anu",
  age: 20,
  city: "Chennai",
};

        This works very well when we have one thing.

        But what happens when we have many things?

        Suppose we have three students:

        const student1 = {
  name: "Anu",
  age: 20,
};

const student2 = {
  name: "Rahul",
  age: 19,
};

const student3 = {
  name: "Meera",
  age: 20,
};

        What if we have thirty students?

        What if we have three hundred?

        We could keep giving every student a different variable name. But something feels wrong about that.

        JS Math Reference

        October 3, 2026
        Javascript, Math
        // ============================================================================
// JavaScript Math Reference
// ============================================================================
//
// A compact reference for common mathematical operations in JavaScript.
//
// ============================================================================



// ============================================================================
// ABSOLUTE VALUE
// ============================================================================

Math.abs(5);             // 5
Math.abs(-5);            // 5
Math.abs(0);             // 0

Math.abs(10 - 15);       // 5



// ============================================================================
// MINIMUM AND MAXIMUM
// ============================================================================

Math.min(2, 5);          // 2
Math.min(10, 3, 7);      // 3

Math.max(2, 5);          // 5
Math.max(10, 3, 7);      // 10

Math.min(-5, -2);        // -5
Math.max(-5, -2);        // -2



// ============================================================================
// SQUARE ROOT
// ============================================================================

Math.sqrt(9);            // 3
Math.sqrt(16);           // 4
Math.sqrt(2);            // approximately 1.414

// The Pythagorean theorem:
//
//     c = √(a² + b²)

Math.sqrt(3 ** 2 + 4 ** 2);   // 5



// ============================================================================
// POWERS
// ============================================================================

Math.pow(2, 3);          // 8
Math.pow(5, 2);          // 25

// The ** operator does the same thing.

2 ** 3;                  // 8
5 ** 2;                  // 25



// ============================================================================
// ROUNDING
// ============================================================================

Math.floor(3.9);         // 3
Math.floor(3.1);         // 3
Math.floor(-3.1);        // -4

Math.ceil(3.1);          // 4
Math.ceil(3.9);          // 4
Math.ceil(-3.1);         // -3

Math.round(3.1);         // 3
Math.round(3.5);         // 4
Math.round(3.9);         // 4

Math.trunc(3.9);         // 3
Math.trunc(-3.9);        // -3



// ============================================================================
// RANDOM NUMBERS
// ============================================================================

Math.random();           // A random number from 0 up to, but not including, 1.

Math.random();           // 0.374...
Math.random();           // 0.821...
Math.random();           // 0.092...



// ----------------------------------------------------------------------------
// Random integer
// ----------------------------------------------------------------------------

// A random integer from 0 through 9:

Math.floor(Math.random() * 10);

// A random integer from 0 through 99:

Math.floor(Math.random() * 100);

// A random integer from 1 through 10:

Math.floor(Math.random() * 10) + 1;



// ============================================================================
// CONSTANTS
// ============================================================================

Math.PI;                 // approximately 3.14159
Math.E;                  // approximately 2.71828

Math.SQRT2;              // approximately 1.41421
Math.SQRT1_2;            // approximately 0.70711



// ============================================================================
// TRIGONOMETRY
// ============================================================================
//
// JavaScript uses radians, not degrees.
//
//     180° = π radians
//      90° = π / 2 radians
//
// ============================================================================

Math.sin(0);             // 0
Math.cos(0);             // 1
Math.tan(0);             // 0

Math.sin(Math.PI / 2);   // 1
Math.cos(Math.PI);       // -1



// ----------------------------------------------------------------------------
// Converting degrees to radians
// ----------------------------------------------------------------------------

const degrees = 90;
const radians = degrees * Math.PI / 180;

Math.sin(radians);       // 1



// ----------------------------------------------------------------------------
// Converting radians to degrees
// ----------------------------------------------------------------------------

const radians = Math.PI;
const degrees = radians * 180 / Math.PI;

degrees;                 // 180



// ============================================================================
// INVERSE TRIGONOMETRY
// ============================================================================

Math.asin(1);            // approximately π / 2
Math.acos(1);            // 0
Math.atan(1);            // approximately π / 4

Math.atan2(1, 1);        // approximately π / 4



// ============================================================================
// LOGARITHMS AND EXPONENTS
// ============================================================================

Math.exp(1);             // e

Math.log(Math.E);        // 1
Math.log(1);             // 0

Math.log10(100);         // 2
Math.log2(8);            // 3



// ============================================================================
// SIGN
// ============================================================================

Math.sign(10);           // 1
Math.sign(-10);          // -1
Math.sign(0);            // 0



// ============================================================================
// USEFUL COMBINATIONS
// ============================================================================

// Distance between two points on a number line:

Math.abs(a - b);


// Distance between two points (x1, y1) and (x2, y2):

Math.sqrt(
    (x2 - x1) ** 2 +
    (y2 - y1) ** 2
);


// Clamp a value between a minimum and maximum:

Math.min(Math.max(value, minimum), maximum);


// Round a number to the nearest integer:

Math.round(value);


// Round down:

Math.floor(value);


// Round up:

Math.ceil(value);

        Visualise it#

        At this point, it can be useful to stop reading and experiment with a visualiser.

        Try entering small examples such as:

        const a = {
  x: 10,
};

const b = a;

b.x = 20;

        Watch what happens when a and b refer to the same object.

        Then try:

        let a = {
  x: 10,
};

let b = a;

b = {
  x: 20,
};

        Pay attention to the difference.

        The visualiser is not a substitute for understanding the code.

        Use it to test your mental model.
