    1. Piecewise function#

    Write a piecewise function for the following table

    XY
    00
    11
    22
    33
    44
    55
    64
    73
    82
    91
    100
    11-1

    Assume the domain of this function is [0,11]. All other values evaluate to 0.

    2. Recursion#

    The sequence begins with:

    • First term: 2
    • Second term: 3

    Write a recursive function that calculates the n-th term.

    Sample Values#

    TermValue
    12
    23
    34
    410
    538
    6378

    Using the pattern shown above, implement a recursive function that calculates any term in the sequence.

    3. Count numbers below threshold#

    Given a sequence of n numbers in memory and a threshold k , count how many numbers in the sequence are lesser than k.

    Assume your program starts with:

    3 19 0 3
4 2 7 1
9 0 0 0
0 0 0 0
0 1
    • Cell number 3 should contain the final result.
    • Cell number 4 contains the threshold k (in this case, k=3)
    • Cell number 5 contains the n number of elements in the sequence (in this case, n=4)
    • Cell number 6 is the first number in the sequence
    • Cell number 17 and 18 contain constants 0 and 1

    Assume n (the number of elements in the sequence) will never be greater than 10.
