    The Million-Dollar Warehouse#

    There is an old warehouse on the outskirts of Bangalore. According to the records you found, the warehouse contains a fortune large enough to completely change your life.

    There is one problem: the owners knew exactly how valuable the contents were.

    To protect the warehouse, they decided to install a highly secure automated entrance system. You have been given the responsibility of designing the logic that controls the entrance.

    The entrance is used by employees to access a restricted area. The door remains locked whenever the security system is not active.

    During normal operation, an employee can enter when their access has been authorized. Authorization can be established by presenting a valid access card. A security guard at the entrance may also approve the employee’s entry.

    The warehouse also has an emergency lockdown feature. When lockdown is activated, the door must remain closed, even if an employee would otherwise be authorized to enter.

    Your Task#

    Design the logic for the automated entrance system based on the requirements above.

    Your submission should contain:

    1. The input and output variables, with a clear definition of each.
    2. Truth table — Construct the complete truth table for your Boolean expression.
    3. The Boolean expression for the entrance system.
    4. The logic-gate diagram implementing the Boolean expression.

    Example#

    Suppose the requirement is:

    A security alarm should activate when the system is armed and a door is open. The alarm should remain inactive when the system is in maintenance mode.

    Inputs

    • A — System is armed
    • D — Door is open
    • M — System is in maintenance mode

    Output

    • Y — Alarm is active

    Truth Table

    • Construct the complete truth table to verify your expression and circuit.

    Boolean Expression

    • Y = A · D · ¬M (or) Y = A AND D AND (complement of M)
    • ¬M means complement of M

    Logic Diagram

    • Represent the Boolean expression using the appropriate AND and NOT gates.
