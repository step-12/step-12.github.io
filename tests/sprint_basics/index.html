    Sprint Basics#

    There are a total of 2 questions worth 100 marks in total.

    1. Tracing (30 marks)#

    Trace the following program

    1 2 3 4 3 4 9 1 3 8 13 1 0 6 16 0

    Execute each instruction and show ALL the cells after each instruction executes. Your submission will look something like that

    Before execution:
1 2 3 4 3 4 9 1 3 8 13 1 0 6 16 0

After 1st step:
1 2 3 5 3 4 9 1 3 8 13 1 0 6 16 0

After 2nd step:
....

    2. Sprint Basics (70 marks)#

    Write a program that adds all even numbers from 1 to n.

    For instance, if n is 4 the answer must be 20 (2 + 4 + 6 + 8)

    The input n is specified in cell number 5. The output is expected in cell number 6.

    1  | 3 13 0 1
5  | 4 0  0 0
9  | 0 0  0 0
13 |

    Submission guidelines

    Ensure that you start the program exactly with the above set of numbers. Begin writing your code from cell number 13. Do not change any of the numbers given. Only submit your program as a part of the final solution. You may do rough work in a notebook, but the final submission should contain only the program. Do not include cell numbers on the left hand side.

    Use commas to separate each cell number. Do not forget trailing commas.

    For example, your final submission may look like:

    3,13,0,1,
4,0,0,0,
0,0,0,0,

    Be very careful in copying your final solution over.
